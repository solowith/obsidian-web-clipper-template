* **Solo (独立思考)**：在这个快时代里，拥有自己的见解和节奏，不被 AI 焦虑所裹挟。

本模板专为那些偏爱**系统思考**、探究 **“为什么”** 而非仅仅是“怎么用”的职场人、创业者及开发者设计。

## ✨ 核心特性

### 1. 语义净化 (Title Logic)

* **极致干净**：自动过滤文件名非法字符，去除“知乎”、“少数派”等站名后缀。
* **双语优化**：智能处理中英文标题，确保 Obsidian 文件列表如代码般整洁。

### 2. 第一性原理摘要 (Deep Summary)

* **拒绝碎片**：AI 不再简单罗列事实，而是致力于捕捉文章的**第一性原理**或**反直觉观点**。
* **第三人称洞察**：以 100 字以内的精炼篇幅，直击作者的底层推演逻辑。

### 3. 高价值标签系统 (Intelligent Tags)

* **精准锚点**：完美识别特有术语（如 `Gemini`, `OpenClaw`, `Agent`）与思维模型词（如 `非对称竞争`, `杠杆效应`）。
* **连接未来**：摒弃泛词，让标签成为知识库中真正的连接纽带。

## 🚀 快速开始

1. **安装环境**：确保已安装 [Obsidian Web Clipper](https://obsidian.md/clipper) 浏览器插件。
2. **导入配置**：下载本项目中的 `solowith-clipper-config.json`。
3. **配置文件**：在插件设置中选择 `Import`，导入该 JSON。
4. **开始内化**：点击剪藏后，请务必在 `## 💡 独立思考` 区域留下你当下的直觉。
